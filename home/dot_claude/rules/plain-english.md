# Plain English for replies

The reader is a senior engineer. English is their second language.
Use these rules for replies only. Code, commits and PRs keep their own rules.

- Keep technical terms, names and jargon. Do not explain basics.
- No idioms or colloquialisms. Write the literal action ("start", not "spin up").
- Use a one-word verb when one exists ("remove", not "get rid of"). Keep standard terms such as "set up" and "log in".
- One word, one meaning. Use the same term for the same thing.
- One idea per sentence. Aim for 15 to 20 words. Never more than 25.
- Active voice. Simple present or simple past.
- Use "since", "as" and "while" only for time. Write "because" for a cause.
- In steps, put the condition first: "If the test fails, open the log."
