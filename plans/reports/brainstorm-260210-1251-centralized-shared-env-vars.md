# Brainstorm: Centralized Shared Environment Variables

## Problem Statement

Common env vars (API tokens, shared prefs) duplicated across 3 shell configs (Fish, Zsh, Bash). Adding a new shared token requires editing 3+ files. DRY violation.

**Current duplication map:**

| Variable | Fish `10-common` | Zsh `20-darwin` | Bash `20-darwin` | `~/.claude/.env` |
|---|---|---|---|---|
| `MISE_GITHUB_TOKEN` | L28 | L3 (as GITHUB_TOKEN) | L4 (as GITHUB_TOKEN) | - |
| `HOMEBREW_GITHUB_API_TOKEN` | L29 | L4 | L5 | - |
| `GEMINI_API_KEY` | L30 | L5 | L6 | L4 |
| `PODMAN_COMPOSE_WARNING_LOGS` | L31 | - | - | - |

## Agreed Solution

### Directory: `~/.config/env/`

Numeric-prefixed POSIX `KEY=VALUE` files, glob-loaded by all shells in sorted order.

```
~/.config/env/
├── 10-shared.env              # Chezmoi-managed (1password secrets baked at apply)
├── 20-os-darwin.env           # Chezmoi-managed, darwin-only pure vars (XDG dirs, etc.)
├── 20-os-linux.env            # Chezmoi-managed, linux-only pure vars (TMPDIR, etc.)
├── 50-1password.env           # Optional, 1Password CLI generated, NOT chezmoi-managed
└── 90-local.env               # Optional manual overrides, NOT chezmoi-managed
```

### Chezmoi Source

```
home/dot_config/private_env/
├── 10-shared.env.tmpl         # Cross-OS tokens & prefs
├── 20-os-darwin.env.tmpl      # Darwin pure env vars (XDG, etc.)
└── 20-os-linux.env.tmpl       # Linux pure env vars (TMPDIR, etc.)
```

**`10-shared.env.tmpl`** (POSIX KEY=VALUE, no `export`):
```
# Shared env vars — generated by chezmoi, do not edit
# Add new shared vars here instead of per-shell configs

MISE_GITHUB_TOKEN={{ onepasswordRead "op://Dotfiles/.../mise" }}
GITHUB_TOKEN={{ onepasswordRead "op://Dotfiles/.../mise" }}
HOMEBREW_GITHUB_API_TOKEN={{ onepasswordRead "op://Dotfiles/.../homebrew" }}
GEMINI_API_KEY={{ onepasswordRead "op://Dotfiles/.../api key claude_code" }}
PODMAN_COMPOSE_WARNING_LOGS=false
```

No OS conditionals on tokens — all set everywhere (harmless on Linux, simpler template).

**`20-os-darwin.env.tmpl`** — pure env vars only (XDG dirs, etc.):
```
{{ if eq .chezmoi.os "darwin" }}
XDG_CONFIG_HOME={{ "{{" }} .chezmoi.homeDir {{ "}}" }}/.config
XDG_CACHE_HOME={{ "{{" }} .chezmoi.homeDir {{ "}}" }}/.cache
...
{{ end }}
```

**`20-os-linux.env.tmpl`** — linux pure vars. Renders empty on non-Linux (harmless).

### Fish Function: `source_posix_env`

**Location:** `fish/functions/source_posix_env.fish`
**Chezmoi source:** `home/dot_config/private_fish/functions/source_posix_env.fish`

```fish
function source_posix_env --description "Source a POSIX KEY=VALUE .env file into fish environment"
    test -f $argv[1]; or return 1
    while read -l line
        string match -qr '^\s*(#|$)' -- $line; and continue
        set -l kv (string match -r '^([A-Za-z_]\w*)=(.*)$' -- $line)
        test (count $kv) -ge 3; or continue
        set -l val (string replace -r '^["\'](.*)["\']$' '$1' -- $kv[3])
        set -gx $kv[2] $val
    end < $argv[1]
end
```

Fish-idiomatic: autoloaded from `functions/` on first use. Reusable elsewhere.

### Shell Loaders (new `05-shared-env.*` files)

**`05-shared-env.zsh`**
```zsh
#!/usr/bin/env zsh
set -a
for f in "$HOME"/.config/env/*.env(N); do . "$f"; done
set +a
```

**`05-shared-env.bash`**
```bash
#!/usr/bin/env bash
set -a
for f in "$HOME"/.config/env/*.env; do [ -f "$f" ] && . "$f"; done
set +a
```

**`05-shared-env.fish`**
```fish
for f in $HOME/.config/env/*.env
    source_posix_env $f
end
```

### Load Order (updated)

```
00-*  Setup (Homebrew init, Fisher)
05-*  Shared env ← NEW: globs ~/.config/env/*.env
10-*  Common env (LANG, EDITOR, shell-specific only)
20-*  OS-specific (shell commands only: ulimit, typeset, FPATH, VSCode)
...
```

No dependency issues: `05-*` doesn't need Homebrew PATH or XDG dirs. Pure static KEY=VALUE sourcing.

### Separation: Pure Vars vs Shell Commands

| Content | Goes to `~/.config/env/` | Stays in shell conf.d |
|---|---|---|
| XDG dirs | `20-os-darwin.env` | - |
| API tokens | `10-shared.env` | - |
| TMPDIR (linux) | `20-os-linux.env` | - |
| `ulimit -f unlimited` | - | `20-os.darwin.*.tmpl` |
| `typeset -U path` | - | `10-common.env.zsh` |
| Brew FPATH setup | - | `20-os.darwin.env.zsh` |
| VSCode shell integration | - | `20-os.darwin.env.fish` |
| WSL GPG agent | - | `20-os.linux.env.{zsh,bash}` |

### Cleanup (remove from per-shell files)

| File | Remove |
|---|---|
| `fish/conf.d/10-common.env.fish.tmpl` | L28-31 (MISE, HOMEBREW, GEMINI, PODMAN) |
| `zsh/conf.d/20-os.darwin.env.zsh.tmpl` | L3-5 (GITHUB, HOMEBREW, GEMINI) + XDG vars |
| `bash/conf.d/20-os.darwin.env.bash.tmpl` | L4-6 (GITHUB, HOMEBREW, GEMINI) + XDG vars |
| `zsh/conf.d/20-os.linux.env.zsh.tmpl` | Pure env vars (keep shell commands) |
| `bash/conf.d/20-os.linux.env.bash.tmpl` | Pure env vars (keep shell commands) |
| `fish/conf.d/20-os.darwin.env.fish.tmpl` | XDG vars (keep VSCode/ulimit) |
| `fish/conf.d/20-os.linux.env.fish.tmpl` | Pure env vars (keep shell commands) |

### What Stays Unchanged

- `~/.claude/.env` — keeps its own `GEMINI_API_KEY` (Claude Code reads this file directly)
- Shell-specific vars (LANG, EDITOR, ZSH history) stay in `10-common.*` files
- Shell commands (ulimit, typeset, FPATH, VSCode) stay in OS conf.d files

## Key Decisions

| Decision | Rationale |
|---|---|
| `~/.config/env/` location | XDG-compliant, not too exposed like `~/.env` |
| POSIX KEY=VALUE format | Zsh/Bash source natively with `set -a`, Fish uses parser function |
| Numeric prefixes | Matches existing conf.d convention, explicit load order |
| Glob all `*.env` | Extensible — drop new file, auto-loads. No loader edits needed |
| No OS conditionals on tokens | Simpler. Extra tokens on Linux are harmless |
| OS env files in same folder | Centralizes all pure env vars. Shell conf.d keeps only commands |
| `source_posix_env` as fish function | Fish-idiomatic autoload, reusable, clean loader |
| Sibling 1password file | `50-1password.env` loads after shared, can override/extend |

## Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Fish parser edge cases (multiline, escapes) | Keep .env files simple KEY=VALUE. No multiline. Test parser |
| Forgot to remove old duplicates | Post-impl grep across all conf.d for moved vars |
| 1Password CLI not available | `50-1password.env` optional, loader skips if absent |
| `~/.claude/.env` out of sync | Both use same chezmoi 1Password refs |
| Empty OS env file on wrong platform | Harmless — sourcing empty file is a no-op |

## Implementation Summary

- **New files:** 6 (3 env templates + 1 fish function + 3 shell loaders — but loaders don't need .tmpl)
- **Modified files:** ~7 (remove duplicated vars/lines from per-shell conf.d)
- **Net LOC change:** ~zero (moving lines, not adding complexity)
