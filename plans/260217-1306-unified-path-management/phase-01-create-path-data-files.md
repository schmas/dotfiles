## Key Insights

- Path system uses `private_path/` → maps to `~/.config/path/`
- OS-specific templates wrapped in `{{ if eq .chezmoi.os "..." }}...{{ end }}`
- Whitespace trimming with `-` (e.g., `{{ if ... -}}`) keeps output clean

## Requirements

- File header with format documentation (comments)
- Exact path entries extracted from current per-shell configs
- No functional change to resulting PATH

## Implementation Steps

### 1. Create `home/dot_config/private_path/10-common.path.tmpl`

Content:
```
# Shared PATH entries — generated by chezmoi, do not edit
# One path per line. Default: prepend, no existence check.
# Flags: --check (verify exists), --glob (add dir + subdirs), --append (end of PATH)
# $HOME expanded. Quotes for spaces. # for comments.

$HOME/.local/bin
$HOME/bin  --glob
```

Notes:
- `$HOME/bin --glob` replaces Fish's `for path in $HOME/bin/*/` loop, Zsh's `for dir in ${HOME}/bin/*(/N)`, and Bash's hardcoded `bin/git-scripts`, `bin/macos`, `bin/etc`
- `$HOME/.local/bin` is common across all 3 shells

### 2. Create `home/dot_config/private_path/20-os-darwin.path.tmpl`

Content:
```
{{ if eq .chezmoi.os "darwin" -}}
# macOS PATH entries — generated by chezmoi, do not edit

/opt/homebrew/opt/coreutils/libexec/gnubin  --check
/opt/homebrew/opt/libpq/bin  --check
$HOME/.antigravity/antigravity/bin  --check
{{ end -}}
```

Notes:
- `/usr/local/sbin` dropped — commented out in Fish, only present in Zsh/Bash. If needed, add back without `--check`.
- All 3 paths use `--check` — matches current `if test -d` / `if [ -d ]` guards
- Commented-out openssl paths intentionally omitted

### 3. Create `home/dot_config/private_path/20-os-linux.path.tmpl`

Content:
```
{{ if eq .chezmoi.os "linux" -}}
# Linux PATH entries — generated by chezmoi, do not edit

$HOME/bin/linux  --check
/var/lib/snapd/snap/bin  --check
/snap/bin  --check
{{ end -}}
```

Notes:
- Current Fish has these commented out — we're using Zsh/Bash as source of truth
- All use `--check` since snap dirs may not exist
- Deduplication: current Zsh/Bash add `$HOME/bin/linux` twice — fixed to once
