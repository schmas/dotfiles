# Phase 1: Create Centralized Env Templates

## Context

- Parent plan: [plan.md](plan.md)
- Brainstorm: [brainstorm report](../reports/brainstorm-260210-1251-centralized-shared-env-vars.md)

## Overview

- **Priority:** High (foundational — other phases depend on this)
- **Status:** complete
- **Description:** Create `~/.config/env/` directory via chezmoi with shared and OS-specific POSIX .env templates

## Key Insights

- POSIX `KEY=VALUE` format (no `export`) — Zsh/Bash use `set -a` to auto-export, Fish uses parser function
- Chezmoi `private_` prefix ensures `700` permissions on directory
- OS templates use Go conditionals, render empty on wrong platform (harmless no-op)
- 1Password refs extracted from existing files (exact `op://` paths confirmed)

## Requirements

**Functional:**
- Single source of truth for shared tokens (MISE, GITHUB, HOMEBREW, GEMINI)
- OS-specific pure env vars (XDG dirs on macOS, TMPDIR on Linux) in same folder
- Files render to clean KEY=VALUE output

**Non-functional:**
- `private_env` directory → 700 permissions at target
- Templates must work on both macOS and Linux

## Architecture

## Implementation Steps

### 1. Create `home/dot_config/private_env/10-shared.env.tmpl`

```
# Shared environment variables — generated by chezmoi, do not edit
# Add new shared vars here instead of per-shell configs
MISE_GITHUB_TOKEN={{ onepasswordRead "op://Dotfiles/lzlakqn35xiz2wptj56mhtghdy/Tokens/mise" | quote }}
GITHUB_TOKEN={{ onepasswordRead "op://Dotfiles/lzlakqn35xiz2wptj56mhtghdy/Tokens/mise" | quote }}
HOMEBREW_GITHUB_API_TOKEN={{ onepasswordRead "op://Dotfiles/lzlakqn35xiz2wptj56mhtghdy/Tokens/homebrew" | quote }}
GEMINI_API_KEY={{ onepasswordRead "op://Dotfiles/mnplwh5vf7jxt3ihqu6rtjbshu/api key claude_code" | quote }}
PODMAN_COMPOSE_WARNING_LOGS=false
```

Note: `| quote` wraps token values in double quotes for safety (handles special chars). Fish parser strips quotes correctly. Non-secret values like PODMAN don't need quoting.

### 2. Create `home/dot_config/private_env/20-os-darwin.env.tmpl`

```
{{ if eq .chezmoi.os "darwin" -}}
# macOS environment variables — generated by chezmoi, do not edit
XDG_CONFIG_HOME={{ .chezmoi.homeDir }}/.config
XDG_CACHE_HOME={{ .chezmoi.homeDir }}/.cache
XDG_DATA_HOME={{ .chezmoi.homeDir }}/.local/share
XDG_BIN_HOME={{ .chezmoi.homeDir }}/.local/bin
XDG_LIB_HOME={{ .chezmoi.homeDir }}/.local/lib
XDG_DESKTOP_DIR={{ .chezmoi.homeDir }}/Desktop
XDG_DOWNLOAD_DIR={{ .chezmoi.homeDir }}/Downloads
XDG_DOCUMENTS_DIR={{ .chezmoi.homeDir }}/Documents
XDG_MUSIC_DIR={{ .chezmoi.homeDir }}/Music
XDG_PICTURES_DIR={{ .chezmoi.homeDir }}/Pictures
XDG_VIDEOS_DIR={{ .chezmoi.homeDir }}/Videos
{{ end -}}
```

Note: Merges XDG vars from Fish (7 dirs + 5 base) and Zsh/Bash (5 base). All shells now get full set.

### 3. Create `home/dot_config/private_env/20-os-linux.env.tmpl`

```
{{ if eq .chezmoi.os "linux" -}}
# Linux environment variables — generated by chezmoi, do not edit
TMPDIR=/tmp
{{ if (.chezmoi.kernel.osrelease | lower | contains "microsoft") -}}
DOTFILES_LOAD_FULL_THEME=true
{{ end -}}
{{ end -}}
```

Note: WSL conditional renders `DOTFILES_LOAD_FULL_THEME` only on WSL machines.

- `chezmoi cat ~/.config/env/20-os-darwin.env` outputs XDG vars on macOS, empty on Linux

## Risk Assessment

| Risk | Impact | Mitigation |
|---|---|---|
| 1Password not signed in | Template fails | `chezmoi apply` already requires 1Password — no new dependency |
| Token values contain special chars | Breaks .env parsing | Use `| quote` if needed; test with actual values |

## Security Considerations

- `private_env` → 700 dir permissions. Tokens not world-readable.
- Same 1Password vault refs as current setup — no new exposure surface.
- Tokens baked at `chezmoi apply` time, not at shell startup.
